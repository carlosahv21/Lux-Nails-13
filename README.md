# 💅 Lux Nails 13 - Luxury Studio

Una landing page premium y elegante diseñada para **Lux Nails 13**, un estudio de manicura de alta gama. Construida con un enfoque en el rendimiento, la estética minimalista y una experiencia de usuario fluida.

![Lux Nails Preview](/public/gallery-11.jpeg)

## 🚀 Tecnologías Principales

-   **[Astro](https://astro.build/)**: Framework web para una velocidad ultrarrápida.
-   **[GSAP](https://greensock.com/gsap/)**: Animaciones de alto rendimiento y efectos de scroll parallax.
-   **[Tailwind CSS](https://tailwindcss.com/)**: Estilizado moderno y responsivo.
-   **[Lenis](https://github.com/darkroomengineering/lenis)**: Scroll suave (smooth scrolling) para una navegación fluida.
-   **Lucide Icons & Custom SVGs**: Iconografía limpia y optimizada.

## ✨ Características Destacadas

-   **Galería Interactiva**: Grid asimétrico 6x12 con modales detallados para cada estilo.
-   **Scroll Parallax**: Efectos visuales dinámicos en las imágenes de la galería.
-   **Branding Premium**: Paleta de colores curada (`#A68A64`, `#F2F2F2`, `#1E1E1E`).
-   **Formulario de Contacto**: Validación cliente-side y feedback inmediato.
-   **WhatsApp Directo**: Botón flotante con mensaje predefinido para agendar citas rápidamente.
-   **Performance**: Optimización de carga, precarga de assets críticos y JS consolidado.

## 🛠️ Instalación y Desarrollo

Sigue estos pasos para ejecutar el proyecto localmente:

1. **Clonar el repositorio:**

    ```sh
    git clone https://github.com/carlosahv21/Lux-Nails-13.git
    cd Lux-Nails-13
    ```

2. **Instalar dependencias:**

    ```sh
    npm install
    ```

3. **Iniciar el servidor de desarrollo:**

    ```sh
    npm run dev
    ```

4. **Construir para producción:**
    ```sh
    npm run build
    ```

## 📂 Estructura del Proyecto

```text
/
├── public/          # Imágenes, logos y assets estáticos
├── src/
│   ├── components/  # Componentes Astro (Navbar, Hero, Gallery, etc.)

│   ├── scripts/     # Lógica de animaciones consolidada
│   └── styles/      # Configuración de Tailwind y estilos globales

```
